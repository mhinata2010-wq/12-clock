# 12 CLOCK

黒背景に現在時刻だけを表示する、シンプルなフルスクリーンWeb時計です。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや外部ライブラリは不要です。

## 仕様

- 12時間表記（時:分:秒 + AM/PM）
- 端末のローカルタイムゾーンに基づく自動更新
- PC・スマートフォン対応のレスポンシブレイアウト
- ダーク背景、操作ボタンや日付表示なし
- GitHub Pagesで公開できる静的サイト

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、`main` の `/(root)` を指定してください。PRをmainにマージした後に配信できます。

## 確認項目

- 00:00:00 → 12:00:00 AM、12:00:00 → 12:00:00 PM と表示
- 時・分・秒がPCの現在時刻と一致
- モバイル画面で横にはみ出さない
- タブを切り替えて戻っても時刻が同期する
