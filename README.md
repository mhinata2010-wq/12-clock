# 12 CLOCK

Liquid Glassから着想を得た、時刻だけを表示するフルスクリーンWeb時計です。Appleの公式コンポーネントや素材を利用したものではありません。

## 使い方

`index.html` をブラウザで開くだけで動作します。外部ライブラリ・ビルドは不要です。

## 仕様

- 12時間表記（時:分:秒 + AM/PM）、端末のローカル時刻に同期
- ガラス風パネル（`backdrop-filter` と半透明レイヤー）
- 青と紫の光がゆっくり動く背景アニメーション
- PCのポインター移動に合わせて反射ハイライトが動く演出
- 端末幅に応じて文字とガラス面を縮小するレスポンシブ設計
- `prefers-reduced-motion` の場合は動きを停止
- `prefers-reduced-transparency` の場合は不透明な背景へ切替
- 時計以外のメニュー・ボタン・日付表示なし

## GitHub Pages

Settings → Pages → Build and deployment から **Deploy from a branch** を選び、`main` の `/(root)` を設定します。PRをmainへマージ後に配信できます。

## 確認項目

- 00:00 → 12:00 AM、12:00 → 12:00 PM
- 毎秒更新される（タブ復帰後に追従）
- モバイルサイズで時刻がはみ出さない
- ポインター位置によって反射位置が変わる
- OSの「視差効果を減らす」などの設定でアニメーションが停止する
